# Privacy Policy — Duplicate Tab Closer

_Last updated: September 9, 2026_

Duplicate Tab Closer does not collect, store, transmit, or sell any user data.

## What the extension can see

The extension uses Chrome's `tabs` permission to read the URLs and titles of
your open tabs. This is the minimum access needed to detect tabs that point to
the same page. Chrome's install prompt describes this permission as the
ability to "read your browsing history" — that is Chrome's blanket phrasing
for any extension that can see tab URLs; this extension does not read or
access your actual browsing history.

## What happens with that data

All processing happens locally in your browser, in memory, while the popup or
review page is open. Tab information is never written to disk, never sent to
any server, and never shared with any third party. The extension makes no
network requests, includes no analytics or tracking, and has no remote code.

## Changes

If a future version changes any of the above, this policy will be updated and
the extension's version number incremented accordingly.

## Contact

Questions about this policy can be raised by opening an issue on this
repository.
